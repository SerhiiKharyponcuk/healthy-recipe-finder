# Sprout — Healthy Recipe Finder

Адаптивний каталог рецептів TheMealDB на **Vite + TypeScript + модульному CSS**.

Теплий світлий фон, лісовий зелений, великі фотографії, типографіка із засічками. Інтерфейс англійською, пояснення для команди — українською.

## GitHub Pages

Адреса демо після публікації: https://serhiikharyponcuk.github.io/healthy-recipe-finder/

Workflow `.github/workflows/deploy.yml` збирає й публікує сайт після кожного пушу в `main`. У **Settings → Pages → Source** потрібно обрати **GitHub Actions**. У поточному безкоштовному плані GitHub репозиторій має бути публічним.

Для локального перегляду production-збірки відкрийте http://127.0.0.1:4173/healthy-recipe-finder/ після `npm run preview`.

## Запуск

Потрібен Node.js 22.12+ або 24 LTS. Проєкт перевірений на Node.js 24.

```sh
npm ci
npm run dev
```

Адреса за замовчуванням: http://127.0.0.1:5173/healthy-recipe-finder/

```sh
npm run typecheck  # перевірка TypeScript
npm run build      # перевірка TypeScript і production-збірка в dist/
npm run preview    # локальний перегляд зібраного сайту
```

## Що готово

- Шапка, вступний блок, каталог, фільтри, блок про проєкт і футер.
- Адаптивна сітка: 3 колонки на великому екрані, 2 на планшеті, 1 на телефоні.
- Картка рецепта, збережений стан, детальний рецепт у доступному нативному `<dialog>`.
- Оформлення порожнього результату, помилки, завантаження, сповіщення та друку рецепта.
- Видимий фокус, підписи полів, Escape для закриття, повернення фокусу, підтримка `prefers-reduced-motion`.
- SVG-іконки, локальні фото для оформлення й фотографії рецептів з TheMealDB.

Каталог підтримує пошук за назвою або одним інгредієнтом, комбіновані фільтри категорії й кухні та сортування за назвою. **Surprise me** відкриває випадковий рецепт з TheMealDB.

Коли всі завантажені картки загального каталогу вже показані, **Show more recipes** запитує наступну групу за першою літерою назви. У деталях можна поділитися посиланням, роздрукувати рецепт, додати інгредієнти до списку покупок і перейти до покрокового приготування. Обране, покупки й прогрес приготування зберігаються у браузері.

## Підключення TheMealDB

Офіційна документація: [TheMealDB API Guide](https://www.themealdb.com/documentation#getting-started).
Приклади маршрутів і зауваження щодо типів — у `src/services/README.md`.

Пошук за інгредієнтом повертає короткі картки. При відкритті такої картки застосунок завантажує повний рецепт за ID. Для рецептів з API показуються лише наявні відомості, тому поля часу й порцій приховано. Ключ `1` призначений для розробки. Умови публічного запуску описано в документації сервісу.

## Готові CSS-стани

```html
<div class="skeleton" aria-hidden="true" style="height: 220px"></div>
<div class="error-state" role="alert">Не вдалося завантажити рецепти. Спробуйте ще раз.</div>
<button class="button button-primary" type="button">Знайти рецепт</button>
<button class="category-chip is-active" type="button" aria-pressed="true">Усі рецепти</button>
```

Для майбутніх асинхронних запитів додайте `aria-busy="true"` на контейнер, а повідомлення про результат — у `role="status"`. Клас `.is-loading` лише блокує вказівник; стан клавіатури та `disabled` встановлює ваша логіка.
